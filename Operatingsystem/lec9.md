# *Register*
### smallest and fastest memory , it is a part of cpu itself , it holds temporary data like instructions , memory addresses or immediate results, super fast , used directly by the cpu while executing instructions,very expensive

# *Cache*

### a small memory between register and RAM , stores frequently used instructions and data , so cpu doesnt have to fetch then from RAM again and again

# *Memory*

### it is also called as primary memory or main memory , temporary storage that holds data and programs currently in use,loses all data when power is off

# *Secondary Memory*

### long-term storage like hard-disk,SSD,CD,Pen drive etc. used for saving files,OS,games,videos,apps-anything permanent
