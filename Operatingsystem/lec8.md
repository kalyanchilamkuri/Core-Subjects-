# 32-Bit vs 64-Bit - what's the difference

## It refers to the size of the cpu registers - these are tiny storage locations inside the cpu to store data temporarily during calculations

### 32-bit can hold 32 bits = 4 bytes
### 64-bit can hold 64 bits = 8 bytes

## Memory access (RAM limit)

### 32-bit OS:can access only 2^32 memory addresses = 4gb RAM max
### 64-bit OS:can access 2^64 memory addresses =17 billion GB

## performance benefits of 64-bit os

## *advantages of 64-bit over 32-bit*

### 1) more addressable memory
### 2) better use of resources 
### 3) Faster calculations because it has more registers and big size , especially in apps like video editing,gaming,compiling code,etc
### 4) More data per instruction 
### 5) Instruction cycle = smallest step in processing , a modern cpu may run billions of cycles per second
### 6) Better graphic performance
